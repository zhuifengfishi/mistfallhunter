## まず結論

常に最強のクラスがあるわけではありません。自分が安定して実行できる武器のリズムとチーム内の役割から選び、バランス更新後は判断を見直してください。

## 初心者向けの選び方

Mercenary は前線で何をするかを把握しやすく、最初の比較対象として扱いやすいクラスです。遠距離の間合いのほうが自然なら Blackarrow を試しましょう。緊張する場面でも基本の行動を繰り返せるかを基準にしてください。

## ソロ脱出向けの選び方

ソロでは、安全な退路、ルートの把握、戦闘を切り上げる判断が重要です。短い交戦を選びたい人には Shadowstrix、安定した近接のテンポを好む人には Withered Knight が合う可能性があります。どちらを選んでも、戦利品を持って離脱する判断の代わりにはなりません。

## PvEでの役割

PvEでは万能ランキングを追うより、チームに不足している役割を埋めてください。Mercenary と Withered Knight は前線の空間を保ち、Seer は遠距離支援の組み立てに向き、Blasphemer は近距離で圧力をかけます。これはティア表ではなく役割確認です。

## PvPでの役割

PvPの結果は、タイミング、視界、連携で変わります。Blackarrow は慎重な精度、Shadowstrix は決断力のある側面攻撃、Seer は準備と支援を活かせます。最初の機会を逃した後の行動を一つ決めてから、クラスを評価しましょう。

## チーム内ロール

安定したチームは、空間の確保、圧力、立て直しを分担します。Mercenary と Withered Knight は近接の空間を支え、Seer は遠距離支援、Blackarrow は精密な圧力、Shadowstrix は側面攻撃、Blasphemer はブルーザーの役割を担えます。戦闘前に担当を共有しましょう。

## 6クラス比較

| クラス | 役割の見方 | 向いている人 |
| --- | --- | --- |
| Mercenary | 前線 | 槍と盾の分かりやすいテンポを望む人。 |
| Seer | 遠距離支援 | 安全な間合いから組み立てたい人。 |
| Blackarrow | 精密 | 弓で落ち着いて圧力をかけたい人。 |
| Shadowstrix | アサシン | 短い側面攻撃の機会を選びたい人。 |
| Blasphemer | ブルーザー | 近距離で重い判断をしたい人。 |
| Withered Knight | 耐久近接 | 大型武器で安定したテンポを好む人。 |

## 選択フロー

1. まず近接、遠距離、または中間距離のどれが快適かを決めます。
2. 前線、支援、圧力、側面攻撃のどれを担いたいかを選びます。
3. 一つのクラスで低リスクの試合を複数行い、計画が崩れる場面を記録します。
4. 繰り返す問題を見つけてから変更し、現在のパッチノートを確認します。

## 方法とバランス時点

このガイドは恒久的な強さの順位ではなく、役割とプレイスタイルを比べるものです。基準日は 2026-08-09 です。バランス変更、マップ、編成、習熟度で実用上の答えは変わります。ビルドを決める前に、公式チャンネルで最新情報を確認してください。
